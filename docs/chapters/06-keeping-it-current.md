## Slides that fit

Every slide is laid out in the browser before the PDF is written. Text shrinks a little if it has to; a slide that still does not fit fails the check and names the section to split.

:::book
## Page numbers that are right

The book prints each part on its own to count its pages, writes the index with the real page numbers, then prints the whole book once so the PDF carries bookmarks for every chapter and section.
:::
